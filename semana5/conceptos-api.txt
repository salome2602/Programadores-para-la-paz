La ruta POST /reporte recibe información enviada por un usuario y devuelve una respuesta en formato JSON indicando que el reporte fue recibido.

Esta ruta podría servir en una aplicación comunitaria para recibir reportes de problemas, sugerencias, alertas o solicitudes realizadas por los miembros de una comunidad. De esta forma la información puede almacenarse y organizarse de manera más eficiente.
