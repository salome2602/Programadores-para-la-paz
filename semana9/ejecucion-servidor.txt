Al ejecutar el comando node server.js se inicia el servidor de Node.js.

En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000".

Cuando se visita la ruta /estado, el servidor responde con un objeto JSON que muestra que el servidor está funcionando y que el servicio corresponde a una API comunitaria.

Respuesta obtenida:

{
"estado": "Servidor funcionando",
"servicio": "API comunitaria"
}
